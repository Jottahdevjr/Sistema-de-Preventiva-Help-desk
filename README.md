Help Desk - Controle de Manutenção Preventiva
Este projeto é uma plataforma de Help Desk desenvolvida para simplificar e automatizar a gestão de manutenções preventivas de equipamentos e infraestrutura. O sistema permite agendar rotinas de vistoria, gerenciar chamados preventivos e emitir relatórios para evitar falhas antes que elas ocorram.

🚀 Funcionalidades Principais
Agendamento Automático: Criação de rotinas periódicas (mensal, trimestral) para checagem de equipamentos.

Gestão de Chamados: Abertura, atribuição e acompanhamento do status de cada manutenção.

Histórico de Ativos: Registro completo de todas as intervenções realizadas em cada equipamento.

Notificações: Alertas sobre próximas manutenções pendentes e prazos de vencimento.

🛠️ Tecnologias Utilizadas
Front-end: HTML5, CSS3, JavaScript

Back-end: Node.js / Express.
